# HXMT 暗物质风地球遮挡调制：对稀有强相互作用亚成分（f ≪ 1）的现实灵敏度

> **性质声明**：本文全部数字都是**给定假设下的 forecast**，不是对 HXMT 数据的分析；没有读取任何 HXMT 数据。
> 标【取自笔记】的是从已有五份笔记/脚本/CSV 直接取用的输入，标 **[inference]** 的是本文的计算结果。
> 没有做文献检索；"来源"一律指本文件夹内的文件。
>
> 脚本：`forecast/s8_subcomponent.py`（一条命令 `python3 s8_subcomponent.py`，约 10 s）；
> 图：`forecast/figures/fig7_fmin_vs_mass.png`、`forecast/figures/fig8_subcomponent_m_sigma.png`；

**一句话结论 [inference]**：把探测响应、自遮蔽和系统地板都折进去之后，窗口 W1 没有消失，但"新"的含义随情景大变——
f = 10⁻³ 时即使 ε = 10⁻³ 仍剩约 4.3–4.5 decades² 的新区域（W1 的 30%–32%），此时新区域的大小由现有限制决定而不是由 HXMT 决定；
f = 10⁻⁶ 时纯统计可新探 7.4–10 decades²，ε = 10⁻⁴ 降到 0.5–3 decades² 且几乎全在 m < 3×10⁴ GeV，**ε = 10⁻³ 时没有任何稳健的新区域**。
笔记认为可信的地板正是 10⁻³，所以现实的说法是：ε = 10⁻³ 时 HXMT 能探到的是 f ≳ 3×10⁻⁶–6×10⁻⁵（m = 10⁴ GeV）、3×10⁻⁵–6×10⁻⁴（m = 10⁵ GeV）的亚成分，而不是此前理想估计的 10⁻⁸、10⁻⁷。

## 1. 各通道的 f_min(m, σ)：假设、公式与数值

### Takeaway
三个通道在各自最佳截面处的 f_min/m_GeV（90% CL，模型 R，2.5×10⁸ s）为：统计极限 3×10⁻¹³–1×10⁻¹¹，ε = 10⁻⁴ 时 3×10⁻¹¹–8×10⁻¹⁰，ε = 10⁻³ 时 3×10⁻¹⁰–8×10⁻⁹；一旦有地板，f_min ∝ ε·B/(A·P)，比统计极限差 40–1600 倍。最灵敏的是反符合板计数率（σ ≳ 10⁻²⁰ cm²），但它的 B 是未发表的**假设值**。

f_min(m, σ) = S0_limit(B, ε) × m / [ ρ⟨w⟩ × A_geo × P_rec(σ) × D(σ/m) ]，且当 σ/m 超过该通道的自遮蔽上限或 m < 10³ GeV 时记为不可达。

- 自遮蔽取三档硬截止：**乐观**（HE 5×10⁻²⁵、反符合板 3×10⁻²⁴）、**悲观**（HE 1×10⁻²⁵、反符合板 4.5×10⁻²⁵）、**最坏**（全部 2×10⁻²⁶ cm²/GeV，即粒子必须穿过相邻模块或平台）。图上另画 2×10⁻²⁶ 与 3×10⁻²⁴ 两条包络线。
- 地球不透明条件通过 D(σ/m) 乘入；在本文关心的区域（σ/m ≥ 10⁻²⁹）D = 1，不起作用。

- 读法 [inference]：例如模型 A、m = 10⁵ GeV、σ = 10⁻²² cm²，CsI 类给出 f_min = 1.8×10⁻⁷（统计）/ 2.8×10⁻⁵（ε = 10⁻⁴）/ 2.8×10⁻⁴（ε = 10⁻³）。
- 有地板时 f_min 与活时间无关，只与 ε·B/(A·P) 成正比：低本底、高记录概率的通道占优。模型 A 下 NaI 类虽然 B 低，但只有 2% 的径迹不进 CsI，反而比 CsI 类差约 2 倍；模型 B 下 NaI 类成为最好的 HE 通道（比模型 A 的任何 HE 通道好约 10 倍）。
- 反符合板的不确定性 [inference]：B 在 2000–20000 c/s 之间变化时，有地板情景下的 f_min 成正比地变化 ±3 倍（m = 10⁶ GeV、σ = 10⁻²⁰：ε = 10⁻³ 时 1.5×10⁻⁴ / 4.4×10⁻⁴ / 1.5×10⁻³）。
- 各截面段由谁主导 [inference]（有地板时，按 B/(A·P) 比较，中心 B）：模型 A——σ ≲ 5×10⁻²² cm² 为 CsI 类，约 5×10⁻²²–1.2×10⁻²¹ 为 NaI 类，更大为反符合板；模型 B——σ ≲ 5×10⁻²¹ 为 NaI 类，更大为反符合板。模型 A 下 HE 的"超量程空档"由反符合板接上，但交接处（σ ≈ 10⁻²¹ cm²）的灵敏度比 CsI 类峰值差约 2 倍、比反符合板平台差约 15 倍；模型 B 没有这个凹陷。

### Gaps
- 反符合板的真实计数率、阈值与稳定性未知；本文的 6000 c/s 只是量级假设，是全文最弱的输入。
- CsI 类、反符合板的系统地板是否也能做到 NaI 类同样的 ε，没有任何依据（系统学笔记的 10⁻³ 结论主要针对 NaI 反符合通过事例）；本文对三个通道用了同一个 ε。
- P_rec 只取 central QF；笔记给出的 QF 上下限使 HE 下沿移动约 3 倍，未传播。

## 2. 固定 f = 10⁻³ 与 10⁻⁶：HXMT 可达且尚未被排除的 (m, σ) 区域

### Takeaway
f = 10⁻³：新区域约 4.6 decades²（m = 10³–3×10⁷ GeV，σ = 3×10⁻²⁴–1.7×10⁻¹⁹ cm²），ε = 10⁻⁴ 时不变，ε = 10⁻³ 时仍有 4.3–4.5 decades²（质量上端缩到 2×10⁶ GeV、截面上端缩到 1×10⁻²⁰ cm²）。f = 10⁻⁶：统计极限 7.4–10 decades²，ε = 10⁻⁴ 剩 0.5–3 decades²（m ≤ 3.5×10⁴ GeV），**ε = 10⁻³ 没有新区域**（唯一的例外是模型 B + 乐观自遮蔽下 m < 3.5×10³ GeV 的 0.26 decades²，处在响应表不适用的低质量端，不应计入）。

### Cited Findings
- 【取自笔记】CSV 中 contact 约定的 f < 1 行：f = 0.1、10⁻²、10⁻³、10⁻⁴、10⁻⁶、10⁻⁸ 各有 Skylab、Ohya、mica、XENON1T 单次散射、DEAP-3600、gas cloud 加热、Saturn 环（Picker+2026 的 `table` 级数据）；另有 `estimate` 级的 Chicago EJ-301（只有 10⁻²、10⁻⁴、10⁻⁶）、IMP 7/8（10⁻²、10⁻⁴、10⁻⁶）、XQC（0.1、10⁻²、10⁻³）；CMB 只到 f = 0.1；σ/m 型上限的 sigma_max = 10⁻⁵ 是作图截断 — [existing_constraints.csv](existing_constraints.csv)
- 【取自笔记】W1 的定义：m ≈ 10³–6×10⁷ GeV；max[3×10⁻²², 3×10⁻²⁷·m] ≤ σ ≤ min[1.7×10⁻¹⁹, 3×10⁻²⁴·m]（cm²）；IMP 7/8 一项来自未发表 recast 的换算，可靠性存疑 — [constraints_and_theory.md §4、§5](constraints_and_theory.md)
- 【取自笔记】gas cloud 对亚成分的限制 f < 1.4×10⁻²⁸ m_GeV/σ_c，即 f = 10⁻³ 时排除 σ/m ≳ 1.5×10⁻²⁵ cm²/GeV — [constraints_and_theory.md §5](constraints_and_theory.md)

### Inferences
**怎样取"最近 f"的限制 [inference]**：f = 10⁻³ 与 10⁻⁶ 两个值 CSV 里都有行，Picker+2026 的各组直接使用。对某个 f 没有行的限制，按如下规则：
1. f 介于该限制的两个已列 f 之间：对两块排除区做 **log f 线性 morph**——质量范围两端在 log m 上插值，在范围内同一相对位置处对 log σ_min、log σ_max 插值（f = 10⁻³ 的 Chicago 与 IMP 7/8 即由 10⁻² 与 10⁻⁴ 两组行得到）；
2. f 大于该限制的最大已列 f：用最大 f 的行（排除区只会随 f 增大）；
3. f 小于最小已列 f：视为该限制已消失（XQC 在 f < 10⁻³ 即如此）。
只在 f = 1 才有行的限制（直接探测并集多边形、CDMS-I、MW satellites、Lyman-α 等）因此在 f < 1 时**不起作用**——这在大气遮蔽线以下明显低估了已有限制，所以"新区域"只统计**大气遮蔽线以上**（σ/m ≥ 3×10⁻²⁷ cm²/GeV，W1 所用的值）的部分。

- 只在 f = 1 列出的限制没有 f 缩放版本；Chicago、IMP 7/8、XQC 的 f < 1 行本身是 `estimate` 级。morph 只是几何插值，没有物理模型（多数限制的质量上限 ∝ f、gas cloud 下沿 ∝ 1/f，线性 log-f 插值与这两种标度一致，其他情形未检验）。
- 自遮蔽按硬截止处理；笔记指出实际是渐变的（动能削到 1% 仍可探测，且会把超量程沉积拉回量程内），方向依赖与"半影"未建模。

## 3. 基准点：HXMT f_min 与现有最强 f 上限、增益（decades）

### Takeaway
m = 10⁴–10⁵ GeV 且位于大气遮蔽线以上的点，HXMT 在 ε = 10⁻³ 时仍比 gas cloud 强 1.4–3.0 个量级（纯统计 4.4–5.9 个量级）；σ = 10⁻²⁰ cm² 的点若采信 IMP 7/8 估计，则 ε = 10⁻⁴ 时只剩 +0.4，ε = 10⁻³ 时为 −0.6；m ≥ 10⁶ GeV 且 σ ≤ 10⁻²¹ cm² 的点位于大气遮蔽线以下，Chicago 型无本底地面实验已经相当或更强，HXMT 加地板后落后 1.4–3.8 个量级。

## 4. 一致性检查

### Takeaway
f = 1 的质量可达与预测笔记逐位一致（同一函数）；约束笔记的理想值 f_min ≈ (1–2.4)×10⁻¹² m_GeV 与本文"每次穿越都记录、NaI、5σ、纯统计"的 1.5×10⁻¹² m_GeV 一致，90% 口径低 3.9 倍；折入响应后各通道的统计极限在 3×10⁻¹³–1.3×10⁻¹¹ 之间，差别都有明确来源。

### Cited Findings
- 【取自笔记】f = 1、模型 R、2.5×10⁸ s 的 90% 质量可达：NaI（B = 500）2.5×10¹² / 6.3×10¹¹ / 6.5×10¹⁰ / 6.5×10⁹ GeV（ε = 0 / 10⁻⁵ / 10⁻⁴ / 10⁻³），CsI（B = 8000）8.7×10¹¹ / 5.6×10¹⁰ / 5.6×10⁹ / 5.6×10⁸ GeV；5σ 最小 f：NaI、ε = 0、m = 10⁴ GeV 为 1.5×10⁻⁸ — [forecast_simulation.md 表 7.2、7.3、§8](forecast_simulation.md)
- 【取自笔记】理想估计的输入：单侧通量 n v̄/4 = 2.25×10⁶ f/m cm⁻² s⁻¹（v̄ = 3×10⁷ cm/s），HE 面积 5103 cm²，活时间 1.8×10⁸ s，B = 500 c/s，5σ 需 S ≈ 2×10⁶–5×10⁶（调制份额 0.75–0.3）→ f_min ≈ (1–2.4)×10⁻¹² m_GeV — [constraints_and_theory.md §4](constraints_and_theory.md)

### Inferences
- [inference] 本脚本在 P_rec = 1、A = 2646/3626 cm² 下重算：NaI 2.54×10¹² / 6.32×10¹¹ / 6.52×10¹⁰ / 6.52×10⁹ GeV，CsI 8.70×10¹¹ / 5.58×10¹⁰ / 5.59×10⁹ / 5.59×10⁸ GeV——与表 7.2 一致（直接调用 `sensitivity_lib`，属预期）。
- [inference] 用约束笔记自己的输入重算其理想值：N_cross = 2.07×10¹⁸ f/m，f_min/m = 0.97×10⁻¹²–2.4×10⁻¹²，复现。本文同口径（NaI、P = 1、纯统计）：5σ 为 1.54×10⁻¹² m_GeV，落在该区间内；90% 上限为 3.9×10⁻¹³ m_GeV，低 2.5–6 倍，差别就是 5σ 与 1.28σ 之比 3.9。两者能在 5σ 口径吻合是几项差异相互抵消的结果：约束笔记的"通量×面积"为 2.25×10⁶ × 5103 = 1.15×10¹⁰ f/m s⁻¹，比本文的 1.062×10⁷ × 2646 = 2.81×10¹⁰ 小 2.4 倍，活时间短 1.4 倍（√t 上差 1.2 倍），但其调制份额 0.3–0.75 比模型 R 的 r_eff = 0.164 乐观 1.8–4.6 倍。

## 5. 没有包含的内容（坦率清单）

### Takeaway
最影响结论的三项未建模因素是：反符合板本底与其系统地板（未知）、低质量端（m ≲ 10⁴ GeV）的动能上限、以及自遮蔽的渐变与方向依赖；它们的方向不一致，净效应无法在本文范围内判断。

### Cited Findings
- 【取自笔记】响应表按 m_χ ≫ m_A、各向同性弦长、SHM 速率计算，未含风的方向性、卫星物质减速与姿态；大截面端残余记录概率只作量级参考；上阈、HVT 阈值有约 2 倍（HVT 最多一个量级）不确定 — [detector_response.md §5 Gaps](detector_response.md)
- 【取自笔记】σ/m ≳ 10⁻²⁴ cm²/GeV 的成分会被银盘气体拖成共转（e 折约 1.6×10⁻²⁴），"风"不复存在；m ≲ 400 GeV 到不了 20 keVee，多次散射信号实际需要 m ≳ 10³ GeV — [constraints_and_theory.md §3](constraints_and_theory.md)
- 【取自笔记】模拟未含真实指向历史、活化史、真实占空比；ε 是情景参数而非测量值 — [forecast_simulation.md "模拟没有包含的内容"](forecast_simulation.md)

### Inferences
以下均为 [inference]。
1. **动能上限**：粒子总动能 ≈ 5 MeV × (m/10⁴ GeV)（300 km/s）。m = 10³–10⁴ GeV 时淬灭后只有约 40–400 keVee，与 CsI 阈（约 48 keVee）、HVT 阈（100 keVee）同量级，本文在这一段的 P_rec 偏乐观（尤其反符合板）；另一方面，同一效应使 m ≲ 2×10⁴ GeV 的粒子即便 σ 很大也不会超量程，HE 在模型 A 的 10⁻²¹–10⁻²⁰"空档"可能被部分填上。两个方向都未计算。表 2 因此另列了 m ≥ 10⁴ GeV 的面积。
2. **自遮蔽**：按硬截止，三档数值覆盖笔记给出的 2×10⁻²⁶–3×10⁻²⁴ 范围；实际是随方向渐变的衰减，并改变事例类别与调制模板形状。乐观档的反符合板上限 3×10⁻²⁴ 只对顶部 6 块成立（面积 6750 cm²），本文用了全部 12 750 cm²，在 4.5×10⁻²⁵–3×10⁻²⁴ 之间高估面积约 2 倍（有地板时 B 同比减小，f_min 基本不变）；3×10⁻²⁴ 还高于银盘拖曳的 1.6×10⁻²⁴。
3. **反符合板**：B 未发表；阈值 50–200 keVee 不定使 50% 触发截面在 1.3×10⁻²¹–1.7×10⁻²⁰ 间移动；带电粒子瞬时本底的东西效应等系统项（单块可达百分之十几）是否能压到 10⁻³ 没有依据。
4. **各通道共用同一个 ε**，且 ε 取为该通道总计数率的份额；没有利用通道间比值、对向板差分、被打标/未打标对照等可能降低地板的手段，也没有计入它们可能引入的额外系统项。
5. **未合并通道**，未用 HE 低增益模式（笔记给出其记录窗上移约 4–5 倍）、混合类事例、死时间/spike 计数、LE/ME（窗口 W2）。
6. **QF 与分类不确定性**未传播：CsI(Na) 高能淬灭因子使 HE 下沿移动约 3 倍；PSD 类的划分点是假设；模型 A/B 之外没有中间情形。
7. **现有限制一侧**：f = 1 独有的限制在 f < 1 时被忽略；`estimate` 级行（Chicago、IMP 7/8、XQC 的 f < 1 版本）未经核实；log-f morph 不是物理模型；地球束缚种群、同位素搜索等不在 CSV 中的间接限制未考虑。
8. **统计处理**：线性高斯、本底主导近似；90% 单侧上限口径；晕模型为 SHM，无引力聚焦与子结构；活时间取 2.5×10⁸ s（1.5×10⁸ s 时统计极限差 1.3 倍，有地板的情景不变）。

### Gaps
- 上述各项都需要真实数据（反符合板计数率、阈值历史）或专门的响应模拟（有限质量、含卫星质量模型）才能定量，超出本次"三份笔记合并计算"的范围。
- 最终哪一个 ε 成立，只能由数据上的零检验测出；本文三种情景之间的差别（f = 10⁻⁶ 时新区域从 10 decades² 到 0）就是这一未知量的直接后果。
